# 侧边栏重设计：可折叠玻璃拟态导航

> 日期：2026-05-04
> 涉及文件：`AppLayout.tsx`、`theme.ts`、`global.css`
> 方案：混合方案 — Ant Design Sider + 自定义菜单项渲染 + 底部状态仪表盘

## 概述

将左侧边栏从传统的 260px 固定 Ant Design Menu 重设计为可折叠（260px ↔ 72px）的玻璃拟态风格导航，底部增加迷你仪表盘。目标：消除留白、增强科技感、提升空间利用率。

## 1. 布局与折叠逻辑

### 尺寸
- **展开态**：260px（与现有宽度一致）
- **折叠态**：72px
- **过渡动画**：`0.3s cubic-bezier(0.22, 1, 0.36, 1)`（与现有 hover 缓动曲线一致）

### 折叠触发
- 侧边栏底部中央放置折叠按钮（`<` / `>` 箭头图标）
- 按钮样式：玻璃拟态胶囊形，`rgba(255,255,255,0.06)` 背景，`border-radius: 8px`
- 箭头在状态切换时旋转 180°
- 点击通过 React `useState` 切换 `collapsed` 状态

### 响应式
- 窗口宽度 < 768px 时自动折叠为图标栏
- 监听 `resize` 事件，组件卸载时清理

### 状态管理
- `collapsed` 状态存于 `AppLayout` 组件内（`useState<boolean>`）
- 无需持久化（页面刷新后重置，当前范围可接受）

## 2. 菜单项视觉风格（玻璃拟态）

### 展开态 — 单个菜单项
- 容器：`div` 玻璃拟态样式（替代默认 Ant Design `Menu` 项渲染）
  - 背景：`rgba(255,255,255,0.04)`
  - Hover：`rgba(255,255,255,0.08)`
  - 圆角：12px
  - 内边距：12px 16px
  - 项间距：6px
- **选中态**：
  - 左侧 3px 竖条指示器，颜色 `#52b788`（品牌绿）
  - 背景：`rgba(82,183,136,0.1)`
  - 图标颜色：`#52b788`
  - 文字字重：600
- **图标**：20px，居左
- **文字**：14px，`Inter` 字体，位于图标右侧，间距 14px
- 过渡：`all 0.25s cubic-bezier(0.22, 1, 0.36, 1)`

### 折叠态 — 单个菜单项
- 容器：48×48px 圆形，在 72px 侧边栏内居中
- 玻璃拟态背景：`rgba(255,255,255,0.04)`
- Hover：亮度提升 + Ant Design `Tooltip` 显示中文标签（延迟 300ms）
- 选中态：底部 3px 横条指示器，颜色 `#52b788` + 绿色 `box-shadow` 光晕
- 图标：22px，居中

### 实现方式
- 用自定义 `nav` 元素替代 Ant Design `Menu`，内部用 `div` 映射菜单项
- 每个项通过 `useNavigate` 路由跳转，`location.pathname` 判断激活状态
- 折叠态 tooltip 使用 Ant Design `Tooltip` 组件

## 3. 底部状态仪表盘

### 展开态
- 与菜单项之间用 `1px` 渐变分割线隔开：`rgba(255,255,255,0.06)` → 透明
- 包含 3 个迷你指标卡片，纵向排列：
  1. **监控状态**：绿色脉冲圆点 + "运行中" / "已暂停" 文字
  2. **今日任务**：数字显示（如 "12 次"），从 `/api/dashboard` 获取
  3. **AI 提供商**：当前使用的提供商名称（如 "MiniMax"），读取配置
- 卡片样式：
  - 背景：`rgba(255,255,255,0.03)`
  - 圆角：10px
  - 内边距：12px
  - 卡片间距：6px
- 文字：`rgba(255,255,255,0.45)`，12px，数字用等宽字体

### 数据来源
- 监控状态：从调度器状态推断（检查是否有任务正在运行）
- 任务数：调用 `/api/dashboard` 接口（与仪表盘页面共用数据）
- AI 提供商：从 `/api/settings` 读取 `AI_PROVIDER` 或直接读取环境变量
- 所有数据在组件挂载时通过 `useEffect` 获取，每 60 秒刷新

### 折叠态
- 仅显示折叠按钮 + 一个绿色状态点（同样带脉冲动画）
- 仪表盘卡片隐藏（淡出 + 上滑，0.2s）

## 4. Logo 区域

### 展开态
- 保持现有布局：图标框 + "情报监测" + "INTEL · MONITOR"
- 图标框：更新为玻璃拟态卡片样式（与菜单项风格统一）
- 底部分割线：从实线改为渐变淡出（`rgba(255,255,255,0.06)` → 透明）

### 折叠态
- 仅显示图标（48×48 圆形玻璃卡片，居中）
- Hover：Tooltip 显示 "情报监测"

## 5. 微动效与交互

| 元素 | 触发 | 动画 |
|------|------|------|
| 侧边栏宽度 | 折叠/展开 | `width 0.3s cubic-bezier(0.22, 1, 0.36, 1)` |
| 菜单文字 | 折叠/展开 | `opacity 0.2s`（淡入淡出） |
| 底部仪表盘 | 折叠 | `opacity 0.2s` + `translateY(-8px)` |
| 折叠按钮箭头 | 状态切换 | `transform rotate(180°) 0.3s` |
| 菜单项 hover | 鼠标进入 | 背景亮度 `0.25s`，图标 `scale(1.08)` `0.15s` |
| 菜单项点击 | 鼠标按下 | `scale(0.95)` 反馈，100ms |
| 状态圆点 | 始终 | `box-shadow` 脉冲动画，2s 无限循环 |
| Tooltip（折叠态） | Hover，延迟 300ms | Ant Design 默认 tooltip 动画 |

## 6. 需修改的文件

| 文件 | 变更内容 |
|------|---------|
| `frontend/src/components/AppLayout.tsx` | 主要重写：自定义导航、折叠逻辑、底部仪表盘、全部动效 |
| `frontend/src/theme.ts` | 少量：新增/更新 Menu token 适配新样式 |
| `frontend/src/global.css` | 少量：新增侧边栏动画关键帧（脉冲、折叠过渡），更新 `.ant-menu` 覆写 |

## 7. 不在范围内

- 不改动路由（现有路由保持不变）
- 不新增页面或导航项
- 不持久化折叠状态（跨会话重置）
- 不做移动端底部 Tab 栏（响应式自动折叠已足够）
- Header 组件仅做折叠态对齐所需的最小调整
