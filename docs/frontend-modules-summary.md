### 四种模式

| 模式 | 触发条件 | UI 变化 |
|------|---------|---------|
| **初始设置** | 后端 `/auth/status` 返回 `needs_setup: true` | 标题变为"初始设置" / "INITIAL SETUP"，按钮变为"初始化系统"，隐藏注册/重置链接 |
| **登录** | 默认 | 用户名+密码，按钮"登录" |
| **注册** | 点击"注册新账号" | 按钮"注册"，成功后自动登录 |
| **重置密码** | 点击"忘记密码？" | 多一个"新密码"输入框，先验证旧密码再更新 |

### 状态

| 状态 | 表现 |
|------|------|
| 检查中 | 页面空白（不渲染） |
| 正常 | 显示表单 |
| 错误 | Alert 红色横幅，可关闭（401=密码错、409=用户名已存在、网络=连接失败） |
| 成功 | Alert 绿色横幅，600ms 后自动跳转 |

### 背景装饰

- 全屏暖色渐变光晕（`rgba(15,118,110,0.04~0.06)`）
- 左上 + 右下角 L 形边角线
- 卡片顶部 3px 绿色渐变装饰线

### 六大区域详解

#### A. 顶部状态栏
- 标题 "◆ INTEL COCKPIT"（绿色菱形）
- SYSTEM OPERATIONAL 绿点状态
- 实时时钟 HH:MM:SS · YYYY-MM-DD（每秒刷新）
- 页面运行时间 UPTIME（秒级自增计时器）

#### B. KPI 卡片行（6 个）
每个卡片包含：
- 数值动画（requestAnimationFrame 从 0 递增到目标值）
- SVG 环形进度条（每种颜色不同 dash 配置）
- 图标 + 标签 + variant 配色（green/amber/cyan/rose/purple）

| KPI | 图标 | 配色 |
|-----|------|------|
| 监测目标 | AimOutlined | green |
| 活跃目标 | ThunderboltOutlined | amber |
| 网站监测 | GlobalOutlined | cyan |
| 今日监测 | ClockCircleOutlined | green |
| 成功 | CheckCircleOutlined | purple |
| 失败 | CloseCircleOutlined | rose |

#### C. 平台监测状态（左上卡片）
- **摘要条:** Platforms 数 / Events 数 / Success%（百分比）
- **环形图 (PlatformDonut):** SVG 手绘 Donut 图，6 色科技风配色，中心显示总数 + "EVENTS" 标签，右侧图例列表
- **平台网格 (PlatformItem):** 每平台一行，含：
  - 状态圆点（online=绿 / degraded=黄 / offline=红）
  - 平台名 + 成功率 + 迷你进度条
  - 右侧数字
- **7日趋势图 (TrendChart):** 纯内联 SVG 折线图，绿色面积 = 成功，红色虚线 = 失败，X 轴日期标签每 2 个显示 1 个

#### D. 系统健康 & 舆情概况（右上卡片）
- **系统组件区:**
  - OpenCLI 状态（安装/运行，惰性加载 `/dashboard/health`）
  - Chrome CDP 连接状态
  - AI Provider + Model 名称
  - 每项：圆点（绿/灰）+ 标签 + 详情 + 状态文字（ON/OFF）
- **数据概览区 (4 格迷你统计):**
  - 舆情任务数 / 采集帖子数 / 情报报告数 / 进行中数
- **进行中提醒:** 如有情报报告生成中，显示闪烁圆点 + 文案

#### E. 信号馈送 (Signal Feed)（全宽卡片）
- 最近监测结果的 Timeline 列表
- 每项 (FeedItem) 含：
  - 时间戳（HH:MM:SS）+ 竖线连线（CSS timeline 效果）
  - 平台标签 (配色徽章)
  - 目标名 + 外部链接
  - 状态标签 (SUCCESS=绿 / FAILED=红 / PENDING=黄)
  - **折叠态:** AI 摘要首行预览
  - **展开态（点击切换）:**
    - AI 分析区（绿色标题 + 清理后的文本，过滤 `<think>` 标签）
    - 贴文列表，每篇含：
      - 作者头像 + 昵称
      - 标题（HTML sanitized）
      - 元信息（发布时间、点赞数、评论数）
      - 正文内容（HTML sanitized）
      - 原文链接
      - 图片（Image.PreviewGroup，最多 9 张）
- **轮询:** 有 pending 记录时每 5s 自动刷新，全部完成后停止

#### F. 底部状态栏
- SYS.ID / UPTIME / AI ENGINE / TOTAL TARGETS / TODAY / SUCCESS RATE
- 等宽字体，半透明文字，绿色高亮数值

### 状态处理

| 状态 | 表现 |
|------|------|
| Loading | 6 个 Skeleton KPI 卡片 + 4 个 Skeleton 方框 |
| 空数据 | data 为 null 时返回 null（不渲染） |
| 有 pending | 每 5s 自动轮询刷新 |
| 无数据模块 | "暂无热点数据" / "暂无趋势数据" / "暂无监测结果" / "暂无平台数据" |

### 依赖 API

| API | 用途 |
|-----|------|
| `GET /api/dashboard` | KPI 统计 + recent_results + trend_data |
| `GET /api/dashboard/overview` | 热点、舆情、情报、系统健康汇总 |
| `GET /api/dashboard/health` | OpenCLI / CDP 实时状态（惰性加载） |
| `GET /api/schedule/status` | 调度任务状态（判断是否有运行中任务） |

### 账号卡片 (AccountCard)

### 添加/编辑弹窗 (Modal 560px)

| 字段 | 组件 | 必填 |
|------|------|------|
| 平台 | Select (platformOptions) | ✅ |
| 账号名称 | Input | ✅ |
| 账号 URL | Input | ✅ |
| 头像 URL | Input | 否 |
| 重要性 | Select (高/中/低) | 否 |
| 调度模式 | Select：每天定时 / 高级 Cron | — |
| 监测小时 + 分钟 | InputNumber (0-23 / 0-59) | 简单模式 |
| Cron 表达式 | 多行 Input（可增删行） | Cron 模式 |
| 抓取数量 | InputNumber (1-100) | — |
| 时间范围 | InputNumber (0-365 天) | — |
| 启用 | Switch | — |

### 立即执行流程

1. 调用 `POST /api/schedule/run/{id}`
2. 获取 `result_id`
3. 每 2s 轮询 `GET /api/results/{result_id}`
4. success → 提示完成 / failed → 提示失败 / 最多 60 次

### 状态

| 状态 | 表现 |
|------|------|
| Loading | 4 个 Skeleton 卡片 |
| 空列表 | "暂无社交账号，点击添加账号开始监控" |
| 有数据 | 卡片列表 |
| 执行中 | runningId 对应卡片显示旋转加载 |

#### AI Provider 配置卡片×3 (ProviderCard)

- 仅 API Key 配置 + 测试

- 每个有"恢复默认"/"清空（使用默认）"切换按钮
